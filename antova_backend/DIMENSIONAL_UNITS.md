# Dimensional Units

This file defines the dimensional vocabulary for this codebase.
Generated by dimensional-analysis plugin.

## Base Units
- `{EUR}` - Leveling currency: headline, adders, exposures, true evaluated price
- `{CCY}` - Foreign bid currency before FX
- `{USD}` - LLM API cost (COGS), never mixed with bid money
- `{A}` - Current (kA parsed to A)
- `{V}` - Voltage (kV parsed to V)
- `{s}` - Short-time duration (Ik seconds)
- `{K}` / `{°C}` - Ambient temperature (Python compares in K, TS in °C)
- `{m}` - Altitude
- `{kg}` - Busbar copper mass
- `{h}` - Site labour hours
- `{day}` - Calendar days (float, transit, FAT days)
- `{week}` - Lead time, delay, LD period
- `{month}` - Warranty, commissioning lag
- `{bay}` - Switchgear bays/panels
- `{lot}` - Lump-sum line
- `{load}` - Heavy-haul truck loads
- `{%}` - Percentage points 0-100 (LD cap, liability cap, add-back realisation)
- `{1}` - Dimensionless (copper/freight multipliers, confidence, 0/1 flags)
- `{token}` - LLM tokens
- `{gap}` - Count of unpriced deviations (scenario allowance)

## Derived Units
- `{EUR/bay}`, `{EUR/lot}`, `{EUR/kg}`, `{EUR/h}`, `{EUR/day}`, `{EUR/month}`, `{EUR/load}` - Rate-table rates; every cost line is `qty{X} * rate{EUR/X} -> {EUR}`
- `{EUR/week}` - Buyer cost of delay
- `{EUR/gap}` - Scenario allowance per unpriced gap
- `{EUR/CCY}` - Dated FX rate
- `{%/week}` - LD rate normalised to per week
- `{USD/Mtok}` - LLM list price
- Conversion factors: `{week/month}=52/12`, `{week/day}=1/7`, `{week/working-day}=1/5`, `{month/year}=12`, `{m/ft}=0.3048`, `{A/kA}=1000`, `{V/kV}=1000`

## Precision Prefixes
- `D2` - Money in cents (Decimal ROUND_HALF_UP in Python; TS money.ts Decimal, pipeline.ts float)
- `D3` - TS display / shortfall rounding
- `D4` - USD API cost
- `D6` - Week values (`round(weeks, 6)`)
- `D9` - Percent normalisation tolerance
